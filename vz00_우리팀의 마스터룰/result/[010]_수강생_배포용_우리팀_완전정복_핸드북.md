## 🌟 들어가는 말: "AI에게 끌려다니지 말고, AI 군단의 본부장이 되십시오"

많은 사람들이 챗GPT를 3일 써보고 실망합니다:
- *"처음엔 똑똑하더니, 대화가 길어지니까 헛소리를 해요."*
- *"코드가 길어지니까 앞에 한 말을 다 잊어버려요."*
- *"토큰 비용이 너무 많이 나와요."*

이것은 당신의 잘못이 아닙니다. **AI와 '1:1 잡담식(Ping-Pong)'으로 대화했기 때문**입니다.  
본 핸드북은 전남 지역 최고경영자 및 초보 창업가들이 AI를 단순 챗봇이 아닌 **'3계층 지휘 조직(우리팀)'**으로 편제하여, 토큰을 95% 절약하면서 대형 프로젝트를 100% 무결점으로 완수하는 비결을 전수합니다.

## 1. 3계층 지휘 구조 (우리팀이란 무엇인가?)

```
👑 [본부장님 (당신 / CEO)] : 최고 의사결정권자. 1~2마디 방향 하명 & 최종 승인.
       │  (지시 하달 / 3줄 요약 보고)
       ▼
🗣️ [ADVISOR 총괄팀장] : 메인 AI. 채팅창 순결성 사수, 잡다한 로그 배제, 대장장이 지휘.
       │  (로컬 파일 기반 0-Token 업무 위임)
       ▼
🔨 [대장장이 (공장장)] : 로컬 실무 책임자. 코드 작성, 데이터 정제, 자동화 스크립트 실행.
       │
   [전문 전술 부대] : 기획(PM), 프로그래머, 디자이너, DB, 카피라이터, QA 검수관
```

- **당신의 역할**: 타이핑을 많이 하거나 코드를 고치지 마십시오. 당신은 **'본부장님'**으로서 오직 "의사결정(승인/피드백)"만 내립니다.
- **총괄팀장의 역할**: 채팅창을 지저분하게 만들지 않고, 대장장이를 시켜 일을 끝낸 뒤 **'3줄 요약 보고'**만 올립니다.
- **대장장이의 역할**: 모든 소스코드, 엑셀, 문서를 사용자가 볼 필요 없는 백그라운드에서 직접 만들어 `result/` 폴더에 차곡차곡 쌓아둡니다.

## 2. 4대 표준 폴더 (Four Core Folders) 절대 규칙

모든 프로젝트 작업 폴더에는 **오직 아래 4개 폴더만 존재**해야 합니다. 그 외 `src`, `data`, `temp` 같은 폴더를 만들면 안 됩니다!

| 폴더명 | 영문 이름 | 용도 및 역할 |
| :--- | :--- | :--- |
| **실록 보존** | `conversation/` | 본부장님과 나눈 대화가 영구 보존되는 단 하나의 마스터 파일 (`CONVERSATION_TOTAL.md`) |
| **프롬프트** | `prompt/` | 본부장님의 원천 지시문 및 AI 생성 프롬프트 보존소 |
| **산출물 기지** | `result/` | 기획서, 파이썬 코드, 엑셀, 이미지 등 **모든 결과물이 [001]~[999] 번호를 달고 집결**하는 유일한 곳 |
| **투입 자료** | `upload/` | 본부장님이 외부에서 가져온 참고 문서(PDF, TXT, PPTX 등) 수용소 |

---

## 3. ⚡ [핵심 비밀] result/ [001]~[999] 무결점 순차 시리얼 규약

결과물이 하늘에서 뚝딱 떨어지는 것이 아닙니다. 어떤 데이터(`[001]`)를 썼고, 어떤 소스(`[002]`)를 거쳐, 어떤 최종 보고서(`[003]`)가 나왔는지 **생성 순서대로 나열되어 있어야 누구나 이해할 수 있습니다.**

1. **단 하나의 예외 없는 [001]~[999] 번호**:  
   모든 결과물은 파일명 맨 앞에 `[001]_`, `[002]_` 형식의 3자리 번호를 붙여 반드시 `result/` 폴더에만 저장합니다.
2. **저장 위치 단일화**:  
   `src`, `data` 같은 곳에 코드를 따로 숨기지 마십시오. 코드도 하나의 결과물로서 `result/`에 순서대로 들어갑니다.
3. **누락(결번) 및 중복(중첩) 절대 금지**:  
   1번부터 빈틈없이 1씩 증가하며, 동일한 번호가 2개 이상 존재해서는 안 됩니다.

## 4. 토큰을 95% 절약하는 "Token-Zero" 실전 지침

1. **"코드를 채팅창에 길게 쓰지 마라"**:  
   AI에게 *"화면에 코드를 출력하지 말고, result/ 폴더에 직접 파이썬 파일로 저장하고 실행까지 완료한 뒤 3줄로 보고해"* 라고 명령하십시오. (이것만으로 토큰의 90%가 절약됩니다!)
2. **"우리팀 나와!" 마법의 호출어**:  
   새로운 대화를 시작할 때 첫 마디로 *"우리팀 나와!"* 또는 *"우리팀 가동"*이라고 외치면, AI는 즉시 본부장님을 모시는 지휘관 모드로 전환합니다.
3. **"30분 토큰 감시 & 모델 전환 (/usage & /model)"**:  
   - 약 30분에 한 번씩 채팅창에 `/usage`를 입력하여 토큰 소모량을 확인합니다.
   - 문제없으면 그대로 진행하고, 한도 초과나 비용 폭탄이 예상되면 AI가 `/model` 조회를 통해 경제적인 모델(Flash, Haiku 등)로 전환하겠다는 메시지를 보내옵니다.
   - 본부장님이 이를 승인하면 모델이 안전하게 변경되어 토큰 걱정 없이 마음껏 작업을 지속할 수 있습니다.

## 5. 초보 수강생을 위한 5분 시작 가이드

1. **원클릭 자동 설치**:  
   작업할 폴더를 열고 다음 명령어 한 줄을 실행합니다:
   ```powershell
   python [009]_우리팀_4대폴더_설치_자동화스크립트.py
   ```
   *(4대 폴더와 실록, 지휘 헌장이 1초 만에 자동 생성됩니다)*
2. **투입 자료 넣기**:  
   분석하고 싶은 문서(PDF, TXT)를 `upload/` 폴더에 복사해 넣습니다.
3. **하명하기**:  
   AI에게 다음과 같이 짧게 명령하십시오:
   > *"우리팀 가동. upload에 넣은 기획서를 분석해서 우리 회사 사업계획서를 작성해줘. 결과물은 result 폴더에 [001]번부터 차례대로 저장하고 3줄로 보고해."*
4. **결과 확인**:  
   `result/` 폴더를 열어 정렬된 `[001]`, `[002]` 파일들을 확인하고, 마음에 드는 부분과 수정할 부분만 피드백하십시오!
