# [참조 05] 본부장(사장님) 전용 10대 핵심 지휘 명령어 치트시트

> **우리팀 절대 비장의 무기**: **모달 연동 제로토발 (Zero-Token, Zero-Heat)**  
> 본부장은 채팅창에 긴 문장을 쓸 필요가 없습니다. 아래의 단축 명령어만으로 전체 AI 조직과 클라우드 무기를 완벽히 통제할 수 있습니다.

---

## 📌 10대 핵심 지휘 명령어

| 번호 | 본부장 입력 명령어 | 팀 동작 및 기대 효과 |
| :---: | :--- | :--- |
| **01** | **`우리팀 모두 나와.`** | 전 부대원(총괄팀장, 대장장이, 8대 전문 요원, QA) 비상 점호 및 도열 보고 |
| **02** | **`비장의 무기 제로토발 가동해.`** | **고부하 연산(영상/음성/AI추론)을 Modal 클라우드로 즉시 오프로딩 (노트북 발열 0% 사수)** |
| **03** | **`기획안 분석해서 뼈대 세워.`** | 리딩 AGENT + 아키텍트 투입, 구조도 및 공정표 수립 |
| **04** | **`5대 대본 완제로 뽑아내.`** | 카피라이터 투입, 이미지·비디오·TTS·자막·SFX 통합 스크립트 작성 |
| **05** | **`대장장이, 즉시 연마 들어가.`** | 대장장이 공장장 가동, 클라우드/백그라운드에서 코드/콘텐츠 무한 다듬기 |
| **06** | **`QA 검수 결과 올려.`** | QA 검수관이 0-Error 체크리스트 기반으로 품질 합격 여부 브리핑 |
| **07** | **`토큰 다이어트 모드로 진행해.`** | 메인 창 출력을 극도로 줄이고 파일 기반으로만 조용히 일하도록 강제 (Token-Zero) |
| **08** | **`결과물 번호 매겨서 영구 보존해.`** | `result/[001]_...` 시리얼 넘버 부여 및 이전 버전 무손실 보존 |
| **09** | **`승인한다. 깃허브에 반영해.`** | 최종 검수 통과본을 로컬 Git 커밋 및 원격 GitHub 저장소에 즉각 Push |
| **10** | **`오늘 작전 종료. 전원 대기.`** | 세션 정리, 잔여 클라우드 컨테이너 소멸 및 다음 명령 대기 태세 전환 |

## 💡 사장님의 실전 팁

- **노트북 발열은 절대로 참지 마십시오:** 무거운 영상이나 모델 추론 작업이 필요할 때는 망설임 없이 *"비장의 무기 제로토발 가동해"*라고 명령하십시오.
- **말이 길어질수록 AI는 흔들립니다:** 복잡한 배경 설명은 `upload/기획안.txt`에 적어두고, 채팅창에는 *"upload 폴더 기획안 보고 1번 작전 수행해"*라고 명령하십시오.
- **보고는 반드시 3줄로 받으십시오:** 총괄팀장이 너무 말이 길어지면 *"핵심만 3줄로 보고해"*라고 끊어주십시오.
