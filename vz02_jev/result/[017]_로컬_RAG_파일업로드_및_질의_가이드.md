## 1. 개요
로컬 LLM(`gemma2:2b`, `hermes3:8b` 등)을 이용해 본부장님의 내부 문서(강의안, 기획서, 보고서, 텍스트)를 바탕으로 정확한 사실에 기반한 답변을 얻는 RAG(Retrieval-Augmented Generation, 검색증강생성) 수행 매뉴얼입니다.

---

## 2. ⚡ 방법 1: 가장 편하고 강력한 전용 실행기 활용 (추천)

### [단계 1] 질문하고 싶은 문서를 `upload/` 폴더에 복사
- 작업 경로: `C:\Users\note\vz\vz02_jev\upload\`
- 예: `curriculum_summary.txt`, `사업계획서.txt` 등

### [단계 2] 파워쉘에서 실행 명령어 1줄 입력
```powershell
python result/[016]_JEV_로컬RAG_문서질의_실행기.py --file upload/curriculum_summary.txt --question "본 과정의 핵심 교육 목표를 3줄로 요약해줘."
```
- **특징**:
  - 문서 내용을 자동으로 읽고 로컬 AI(`gemma2:2b`)가 팩트 기반 정밀 분석.
  - 옵시디언 2nd Brain(`00_Inbox_수신함/JEV_의사결정노트/`)에 결과 노트를 자동 생성 및 영구 보존.

---

## 3. ⚡ 방법 2: 파워쉘 터미널에서 즉시 파이프라인 주입 (0초 인스턴트 RAG)
별도 스크립트 실행 없이 파워쉘에서 문서 내용을 바로 읽어서 `ollama`로 전달하는 방식입니다.

```powershell
Get-Content upload\curriculum_summary.txt -Raw | wsl ollama run gemma2:2b "위 문서를 바탕으로 질문에 답해줘: 이한규 대표의 강의 일시와 주제는?"
```
