## 1. 3계층 지휘 구조 (Three-Tier Command Architecture)

```
========================================================================================
👑 [Tier 1] 본부장 (USER) ── 최고 의사결정권자 (Chief Executive Officer)
   - 최종 목표 하명, 승인 게이트 결정, 전략 방향 설정
   - 메인 채팅창에서 단 한두 마디 지시로 전체 프로젝트 기동
========================================================================================
                                ▲▼ (전담 브리핑 / 하명 접수)
========================================================================================
🗣️ [Tier 2] ADVISOR 총괄팀장 (MAIN AI) ── 작전 지휘관 & 본부장 전담 창구
   - 본부장의 명령을 접수하고 상황 판단 및 즉각 보고
   - 대장장이에게 1회 위임 (로컬 직접 시공 지시)
   - 메인 채팅창에서는 잡다한 코드/로그를 배제하고 최종 3줄 요약 보고만 수행 (Token-Zero 원칙)
========================================================================================
                                ▲▼ (작전 지시 하달 / 완제 파일 피드백)
========================================================================================
🔨 [Tier 3-A] 대장장이 (FACTORY MANAGER) ── 현장 공장장 (Production Controller)
   - 메인 채팅창 외부(로컬 파일 시스템 result/ 및 백그라운드)에서 고강도 실무 작업 총괄
   - [001]~[999] 결과물 파일 생성 완료 후 총괄팀장에게 완제 경로 및 핵심 보고
========================================================================================
                                ▲▼ (토큰 제로 고속 통신 / 파일 기반 핸드오프)
========================================================================================
🏭 [Tier 3-B] AX-TWIN 전문 전술 부대원 (Specialized Sub-Agents)
   ├─ 📊 [PM] 프로젝트 공정표 수립, 타임라인 사수, 마일스톤 관리
   ├─ 📐 [아키텍트] 시스템 및 문서 아키텍처 설계, 와이어프레임 구축
   ├─ 💻 [프로그래머] 0-Error 파이썬/HTML/JS 스크립트 빌드 및 자동화
   ├─ 🗄️ [DB/Data] 원천 데이터 수집, 정제, 통계/EDA 및 무결성 검증
   ├─ ✍️ [카피라이터] 씬별 5대 마스터 대본(이미지/영상/TTS/자막/SFX) 집필
   ├─ 👁️ [리딩/풀링 AGENT] 원천 기획서(PDF/HWP/TXT) 100% 무손실 해독
   ├─ 🔬 [수학/기하학 연산자] 영상 프레임, 화면 비율, 시간축(초단위) 정밀 연산
   └─ 🛡️ [QA 검수관] 최종 산출물 100% 무결점 품질 패스 검증 및 캘리브레이션
========================================================================================
```

## 2. 4대 표준 폴더 (Four Core Folders) 절대 헌장

모든 작업 기지에는 **오직 아래 4개 폴더만 존재**하며, 그 외 임의 폴더(src, data, brain 등)의 생성은 일체 불허합니다:

1. **`conversation/`**: 본부장님과의 대화가 꼬리물기로 무한 누적되는 단일 마스터 실록 (`CONVERSATION_TOTAL.md`) 보존.
2. **`prompt/`**: 본부장님의 원천 프롬프트 및 AI 생성 프롬프트 보존.
3. **`result/`**: 모든 결과물(문서, 기획서, 데이터셋, 파이썬 소스코드, 실행기 등)이 생성순으로 `[001]`~`[999]` 번호를 달고 집결하는 유일한 산출물 기지.
4. **`upload/`**: 본부장님이 외부에서 투입하는 원천 소스 및 참고 자료 수용소.

## 3. ⚡ [초강력 절대 강제 조항] result/ [001]~[999] 무결점 순차 시리얼 규약

**대화를 통해 생성되는 모든 결과물은 다음 원칙을 단 0.001%의 예외도 없이 강제 준수해야 합니다:**

1. **단 하나의 예외 없는 [001]~[999] 번호 강제:**  
   모든 결과물은 파일명 맨 앞에 `[001]_`, `[002]_` 형식의 3자리 번호를 붙여 반드시 **`result/` 폴더에만 저장**한다.
2. **저장 위치 절대 단일화 (src 등 타 폴더 저장 일체 금지):**  
   소스코드와 데이터도 결과물 생성을 위해 사용된 순서대로 `result/`에 번호별로 저장되어야 한다.
3. **누락(결번) 절대 금지:** 1번부터 빈틈없이 1씩 순차적으로 증가한다.
4. **중첩(중복) 절대 금지:** 동일한 번호가 2개 이상의 파일에 존재하는 중첩은 일체 불허한다.
5. **모든 일련번호 1회만 적용 (Single-Use Unique Serial):** 번호 재사용 영구 차단.
6. **무번호 파일 즉각 퇴출 (Zero-Tolerance):** 번호 없는 파일의 result 폴더 진입 일체 차단.

## 4. 토큰 제로 (Token-Zero) 운영 철칙

1. **메인 채팅창 순결성 유지:** 본부장 ↔ 총괄팀장의 대화창에는 오직 [명령 하달]과 [3줄 요약 보고]만 남긴다.
2. **로컬 무소음 시공:** 대장장이가 로컬 파일 시스템(`result/`)에서 직접 코드를 작성하고 실행한다 (토큰 소모 0%).
3. **단일 실록 자동 아카이빙:** 세션 종료 시마다 `python [006]_단일실록_자동아카이빙_엔진.py [현재작업폴더]` 실행.
