## 📌 개요 (Overview)

일반적인 사용자는 AI에게 질문하고 답변을 받는 **"1:1 대화식(Ping-Pong)"**으로 작업합니다.  
이 방식은 코드가 길어지거나 프로젝트가 커질 때 **컨텍스트 오염, 토큰 폭발 과금, AI의 지시사항 망각**으로 3일 만에 100% 붕괴합니다.

**[vz.00_우리팀]** 시스템은 사용자를 최고 의사결정권자(본부장님)로 모시고, ADVISOR 총괄팀장(지휘관)과 대장장이(현장 공장장)가 원팀으로 협업하여, **토큰을 95% 절약하면서 엔터프라이즈급 기획·개발·데이터 결과물을 100% 자립 완결**하는 마스터 운영 체계입니다.

---

## 🚀 3대 핵심 헌장

### 1. 3계층 지휘 체계
- **Tier 1 (본부장님 / CEO)**: 1~2마디 전략 하명 및 최종 승인
- **Tier 2 (ADVISOR 총괄팀장)**: 메인 창 순결성 사수, 잡다한 로그 배제, **[3줄 요약 보고]**
- **Tier 3 (대장장이 & 전문 부대)**: 백그라운드 및 로컬 파일 시스템에서 직접 시공 (Token-Zero)

### 2. 4대 표준 폴더 (Four Core Folders)
- `conversation/`: 단일 마스터 실록 `CONVERSATION_TOTAL.md` 영구 누적
- `prompt/`: 본부장님의 원천 프롬프트 보존
- `result/`: 모든 산출물이 `[001]`~`[999]` 번호 순서대로 집결
- `upload/`: 사용자 원천 자료(PDF, PPTX 등) 수용소

### 3. result/ [001]~[999] 무결점 순차 시리얼 규약
- 대화를 통해 생성되는 모든 결과물은 단 하나의 예외도 없이 `[001]`~`[999]` 번호를 붙여 `result/` 폴더에만 저장.
- 결번(누락) 0%, 중복(중첩) 0%, 무번호 파일 0%!
