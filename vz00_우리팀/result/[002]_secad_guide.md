# SECAD v1.0 — 실행 가이드 & 개발 로드맵

## 📌 즉시 실행 방법

```powershell
# 바로 브라우저에서 열기
Start-Process "C:\Users\note\vz\vz00\result\[001]_secad.html"
```

또는 파일 탐색기에서 `[001]_secad.html` 더블클릭 → Chrome/Edge에서 열림.

### 뷰 & 설정
- 마우스 휠 줌 / Alt+드래그 패닝
- 격자 스냅 (F9)
- 직교 모드 (F8)
- 격자 토글 (G)
- Undo/Redo (Ctrl+Z/Y)
- 전체 보기 (ZE)

### 파일
- JSON 저장/불러오기 (.scd)
- PNG 내보내기
- SVG 내보내기

### 🤖 AI 스케치 분석
- 텍스트 설명 → 도형 자동 생성
- 키워드 파서: 원, 사각, L자형, 기둥, 단면도, 기어, 화살표
- 이미지 업로드 (미리보기)
- 모드: 개념도형/이미지분석/청사진/단순화

## 🗺️ v2.0 로드맵 (다음 단계)

### Phase 1 — 정밀도 강화
- [ ] 트림/연장 실제 교차점 계산
- [ ] 모깎기/모따기 정확한 기하 연산
- [ ] 스냅: 끝점, 중간점, 교차점, 수직 스냅
- [ ] 레이어 패널 (켜기/끄기/잠금)
- [ ] 치수 스타일 설정

### Phase 2 — AI 고도화
- [ ] Google Gemini Vision API 연동
  - 사진/스케치 → 실제 도형 인식
  - "이 건물과 비슷하게" 이미지 참조 생성
- [ ] Claude API 연동
  - 자연어 명령: "왼쪽 사각형을 3배 크게 하고 오른쪽으로 50 이동"
- [ ] 로컬 AI (Ollama + LLaVA)
  - 오프라인 이미지 분석

### Phase 3 — 협업 & 출력
- [ ] DXF 내보내기 (AutoCAD 호환)
- [ ] PDF 출력 (A4/A3)
- [ ] 공유 링크 (LocalStorage → URL 인코딩)
- [ ] 템플릿 라이브러리 (평면도, 전기도, 기계도)

### Phase 4 — 미래전략 특화
- [ ] 3D 개념도 (Three.js 연동)
- [ ] 발표용 애니메이션 (도면 등장 효과)
- [ ] 기업 브랜딩 (로고/색상 적용)
- [ ] QR코드 연동 (도면 링크 생성)
