# [참조 13] 우리팀 사전 검문 및 4대 표준 폴더 자동 스캐폴딩 규약 (Auto-Scaffolding Protocol)

> **제정일시**: 2026-10-05  
> **최고 의사결정권자 하명**: 본부장님 (Chief Executive Officer)  
> **총괄 작전 지휘관**: ADVISOR 총괄팀장 (MAIN AI)  
> **현장 집행 총괄**: 대장장이 (Factory Manager)  
> **적용 범위**: 우리팀이 호출되는 모든 작업 기지 (`vz00~vz99` 및 신규 프로젝트 폴더 전역)  

---

## 1. 제정 배경 및 목적

우리팀의 모든 작업이 100% 무결점으로 성공하기 위해서는 생성되는 모든 결과물이 `result/` 폴더에 `[001]`~`[999]` 번호로 빈틈없이 누적되는 체계가 물리적으로 뒷받침되어야 합니다.  
본 규약은 본부장님의 하명에 따라, **우리팀이 동원되는 모든 폴더에서 작업 개시 전 4대 표준 폴더의 적용 여부를 스스로 검사하여, 이미 적용되어 있다면 건너뛰고(SKIP), 적용되지 않았다면 0.1초 만에 자동 구축(AUTO-APPLY)하는 자율 스캐폴딩 메커니즘**을 규정합니다.

---

## 2. ⚡ Step 0: 사전 검문 및 자동 스캐폴딩 메커니즘

우리팀(`our-team-master`)이 호출되는 순간, 본 대화에 앞서 대장장이와 아키텍트는 아래의 **[Step 0] 사전 검문 게이트웨이**를 필수 실행합니다:

```
[우리팀 호출] "우리팀 모여봐 / 회의합시다 / 작업 시작"
      │
      ▼
┌────────────────────────────────────────────────────────┐
│ 🔍 [Step 0: 4대 표준 폴더 사전 검문 (Pre-flight)]    │
│    - conversation/, prompt/, result/, upload/ 존재?   │
└────────────────────────────────────────────────────────┘
      │
      ├─▶ [Case A: 4대 폴더가 완비되어 있는 경우]
      │    ➔ ⏭️ [SKIP] (멱등성 보장, 기존 파일 및 번호 100% 보존)
      │    ➔ 🔢 result/ 내 기존 최대 번호 자동 감지 (예: [012] -> 다음 [013] 선언)
      │
      └─▶ [Case B: 1개라도 누락 또는 미비된 경우]
           ➔ 🛠️ [AUTO-APPLY] 즉시 4대 폴더 자동 생성:
           │    mkdir conversation, prompt, result, upload
           ➔ 📝 `conversation/CONVERSATION_TOTAL.md` 마스터 실록 생성
           ➔ 🎯 차기 산출물 `result/[001]` 번호 부여 대기 정렬
      │
      ▼
[ADVISOR 총괄팀장 작전 개시 보고]
```

## 3. 세부 실행 프로토콜

### 1) 멱등성 사수 (Idempotency Guarantee)
- 이미 존재하는 디렉토리나 파일을 덮어쓰거나 초기화하지 않습니다.
- 기존 파일이 존재할 경우 `SKIP` 판정을 내리고, `result/` 내의 파일명 패턴(`\[([0-9]{3})\]`)을 스캔하여 다음 가용 번호를 자동으로 계산합니다.

### 2) 제로발열(Zero-Heat) 초경량 실행
- 사전 검문 및 폴더 생성은 무거운 외부 라이브러리 없이 0.05초 만에 완료되는 초경량 파일 시스템 I/O 명령으로만 수행합니다.
- CPU/GPU 부하 0%, 노트북 발열 0%를 철저히 사수합니다.

### 3) 무번호 파일 자동 정렬 (Zero-Tolerance)
- 만약 검문 과정에서 `result/` 폴더 내에 번호가 없는 파일이나 임의 폴더가 발견될 경우, 대장장이는 즉시 정규 번호(`[NNN]`)로 편입하거나 퇴출하여 규약의 순결성을 지킵니다.

## 4. 자동 스캐폴딩 PowerShell 표준 스크립트

```powershell
# 우리팀 4대 표준 폴더 사전 검문 및 자동 구축기
$folders = @("conversation", "prompt", "result", "upload")
$missing = @()

foreach ($f in $folders) {
    if (-not (Test-Path $f)) {
        $missing += $f
        New-Item -ItemType Directory -Path $f -Force | Out-Null
    }
}

if (-not (Test-Path "conversation\CONVERSATION_TOTAL.md")) {
    Set-Content -Path "conversation\CONVERSATION_TOTAL.md" -Value "# 🏛️ [CONVERSATION TOTAL] 단일 마스터 실록`n`n> 최초 생성: $(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')`n" -Encoding UTF8
}

if ($missing.Count -gt 0) {
    Write-Host "[우리팀 AUTO-APPLY] 4대 표준 폴더 자동 구축 완료: $($missing -join ', ')"
} else {
    Write-Host "[우리팀 SKIP] 4대 표준 폴더 이미 완비됨 (기존 환경 유지)"
}
```
